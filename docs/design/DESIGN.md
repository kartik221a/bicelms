## Brand & Style

The design system embodies the rigor, precision, and executive polish required for career-defining data education. Tailored for corporate analysts, aspiring data engineers, and business leaders mastering Advanced Excel, Power Query, SQL, Python, and BI dashboards, the interface projects competence, clarity, and momentum.

Drawing from modern high-end SaaS leaders (Linear, Stripe) and tier-one enterprise academies (Coursera for Business, Udemy Enterprise), the visual style adopts a **Modern Corporate / Systematic Minimalist** aesthetic. Layouts favor razor-sharp typographic hierarchy, high signal-to-noise ratios, and intentional white space over ornamental excess. The emotional response is one of instant credibility, academic rigor, and structured career advancement.

## Layout & Spacing

The layout model is governed by a strict 8px incremental grid with generous whitespace to prevent visual crowding in data-dense learning environments.

- **Desktop (1024px+):** 12-column fluid grid, max container width of `1280px` (or `1440px` for multi-pane lesson workspaces), with `24px` gutters and `32px` page margins.
- **Tablet (768px - 1023px):** 8-column layout with `20px` gutters and `24px` margins. Collapsible secondary sidebar navigation for curriculum trees.
- **Mobile (<768px):** 4-column layout with `16px` gutters and `16px` margins. Side-by-side split screens stack into sequential vertical stacks (video/code above syllabus/tasks).
- **Workspace Views:** Course player interfaces (such as interactive SQL query editors and dataset previewers) break out of the standard container into a full-bleed, edge-to-edge docked workstation.

## Elevation & Depth

Visual hierarchy uses low-contrast outlines combined with calibrated, ambient diffused drop shadows to achieve a light, modern SaaS aesthetic.

- **Flat Canvas (`#F8FAFC`):** The default root layer upon which cards and panels rest.
- **Base Surfaces (`#FFFFFF`):** Cards, lesson sidebars, and course directory panels. Paired with a `1px` border of `#E2E8F0` and `box-shadow: 0 1px 3px 0 rgba(0, 0, 0, 0.05)`.
- **Raised Surfaces (Hover / Active Focus):** Interactive course cards and flyout menus elevate slightly using `box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.05), 0 2px 4px -2px rgba(0, 0, 0, 0.05)` and subtle border darkening to `#CBD5E1`.
- **Top Bar & Shell Overlays:** Navy slate (`#0F172A`) header uses zero shadow, relying entirely on clean, planar separation and pure surface contrast. Modals and drawers utilize a dark overlay (`rgba(15, 23, 42, 0.6)`) with high-elevation soft blur (`backdrop-filter: blur(4px)`).
