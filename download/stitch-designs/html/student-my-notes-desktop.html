Key Enterprise ETL Rule

Never skip locale conversion when consuming mixed European and US corporate CSV ledger feeds. Direct implicit conversions corrupt dates into month/day inversions.

Always convert dates to text first if parsing locale mismatches (e.g. DD/MM/YYYY vs MM/DD/YYYY) before invoking Table.TransformColumns.

Split by delimiter at leftmost delimiter index using SplitTextByDelimiter("-", QuoteStyle.None) to preserve internal customer sub-keys.

For dirty numeric columns with currency strings ($ / €), strip non-numeric symbols via regex or Text.Select prior to applying type number casting.

data_object M-Code Snippet (Lesson 4 Production Pattern) 
// Step 3: Parse nested invoice keys safely without schema degradation
let
    Source = Csv.Document(File.Contents("P:\GL_Feeds\Q3_Global_Transactions.csv"), [Delimiter=","]),
    PromotedHeaders = Table.PromoteHeaders(Source, [PromoteAllScalars=true]),
    CleanedCols = Table.TransformColumnTypes(PromotedHeaders, {{"Amount", Currency.Type}}),
    Splits = Table.SplitColumn(CleanedCols, "Invoice_Raw",
        SplitTextByDelimiter("-", QuoteStyle.None),
        {"TransactionDate", "Region_Code", "Invoice_ID"})
in
    Splits
